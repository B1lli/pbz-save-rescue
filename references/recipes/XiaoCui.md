# 小翠 4-A：陆三迁喝下无根仙露的结局

本配方把「小翠」任务从 4-B（陆三迁没喝仙露、后面死去）改回 **4-A**（喝过仙露），并补上这条路线的剧情状态与奖励。它**不是**"完成整个任务"，4-A 走完后任务还在分支 5，属于进行中。

## 来源与验证

- 来自一位玩家 2026-11 的存档：他的「小翠」任务当时已经是 `QC_Succeded`（走的是 4-B，陆三迁已死），4-A / 5 / 6 从未触发。
- 他把 11.14 05:56 的旧档回放了一遍，在陆三迁的笼子前先递了无根仙露，任务走到 4-A 完成、分支 5 开始，拿到书信与「粗糙煌心」。
- 回放前后的差异被整理成 39 条 `slot_ops`，再移植回他最新（51:10）的存档，游戏内确认任务列表与背包正常。
- **只在这一份存档上验证过**；其他周目、其他失败路线没有验证。

## 适用条件

`requires` 会检查：首周目、小翠任务为 `QC_Succeded`、分支 4-B `BranchCompleted` 且 4-A / 5 为 `None`、全局剧情标签里有 `ddsd.陆三迁3.死亡` 与 `ddsd.陆三迁2.没喝仙露`。任何一条不满足，命令会在写出任何文件前整体报错。

不要为了"能用"删掉这些检查。

```bash
python -I scripts/complete_quest.py --quest XiaoCui --target TARGET.json --out-dir patched --dry-run
```

## 修改范围

- 任务记录整体替换为 4-A 版本：分支 1/2/3/2-ex/4-A 完成，4-B 回到 `None`，5 进入 `BranchActivating`。
- 全局剧情标签：移除 `ddsd.陆三迁2.没喝仙露`，补 `ddsd.陆三迁2.有喝仙露`、`ddsd.陆三迁3.完成任务`、`ddsd.陆三迁3.获得书信`。
- 7 个陆三迁相关的 NPC / 笼子组件的状态同步为重放后的样子。
- 物品：书信 `R_070001`、饰品 `AC_MartialWeapon`（粗糙煌心）。已有的物品不会重复添加。
- `ach_ops` 为空：这次回放没有新增成就记录，也不推断 Steam 成就解锁。

## 限制

- 不改变角色数值、材料、主线、其他任务、地图、位置与游戏时长。
- 时间戳会按目标存档的存档时间截断，避免出现"来自未来"的记录。
- 如果玩家的存档在 4-B 之后又推进了很多剧情，应用前建议先 `--dry-run` 看改动清单，确认与预期一致。
