# 赎罪名单 → 白雪儿

在《赎罪名单》里选「算了，放他一条生路」后，原任务可以显示完成，《白雪儿》的任务记录却没有建立。本配方用玩家回档重选、击败铁面并亲自完成《白雪儿》的存档差异，补回这条后续及奖励。

配方的适用范围是首周目、已放走铁面、后街小院的门已用钥匙打开、沾血的项链还在背包里、《白雪儿》未接取。脚本还会核对铁面、女性人偶、记忆之花的状态及奖励是否已经入库。如果钥匙还在，先在游戏里试着开门，再存档预演。任一目标槽不匹配，保留现有存档，以游戏内进度或选择前的备份为准。

```bash
python3 -I scripts/complete_quest.py --quest BaiXue --target TARGET.json --out-dir patched --dry-run
```

预演通过后，去掉 `--dry-run`，按 [存档挽救流程](../../SKILL.md) 备份、打包和装回。请使用与配方一起更新的 `complete_quest.py`，它可以按配方创建缺失的任务记录。

配方将铁面的结果改为击败，并同步他和女性人偶的状态、相关对话、两朵花的收集记录、对应的回忆记录及饰品「雪与血」。交付后消耗原有的沾血的项链。此状态下已经开门，钥匙和杀气琥珀碎片按原档保留。任务和物品的时间按目标槽生成。

来源是一位 Steam 玩家在 build 26367565 的实机重玩。本配方在该玩家的三份原始自动槽副本上预演、应用、重新打包和读回。配方保留原档的角色与主线进度，不移植通关者的首领用时、个人战绩、成就、时间或坐标。其他玩家的游戏内加载及后续周目仍需验证。
